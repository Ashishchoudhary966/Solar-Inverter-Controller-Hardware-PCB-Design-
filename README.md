# Solar-Inverter-Controller-Hardware-PCB-Design-

Responsibilities:

1. Converted hand-drawn schematics into complete digital schematics and production-ready PCB designs using Eagle

2. Designed control boards based on Texas Instruments TMS320F28069 MCU, including gate drivers and peripheral interfaces

3. Developed current and voltage sensing circuits for system monitoring and protection

4. Designed SMPS power supplies, GSM communication modules, LCD interfaces, and supporting analog/digital circuitry

5. Implemented mixed-signal PCB layouts with proper isolation between high-power, analog, and digital sections

6. Applied EMI reduction, grounding, and signal integrity best practices

7. Created custom component libraries and footprints for optimized PCB design

8. Generated BOM, Gerber files, and complete manufacturing-ready design packages


Tools & Technologies:

Schematic Capture
